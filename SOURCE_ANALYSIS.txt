1. EXACT PROJECT TITLE
----------------------
PocketSmart AI: Your Smart Budget & Recommendation Assistant

2. EXACT PROBLEM STATEMENT
--------------------------
Managing budgets across different life needs-like home decor, event planning, or jewelry shopping-can be overwhelming due to the wide variety of products, platforms, and price ranges.

3. EXACT SOLUTION
-----------------
PocketSmart AI addresses this challenge through a GenAI-powered, cross-platform recommendation system that delivers personalized, budget-based suggestions for products and services. Using Gemini 1.5 Flash Pro, PocketSmart AI analyzes user preferences, budgets, and contextual needs to generate curated recommendations from popular platforms such as Amazon, Flipkart, IKEA, Swiggy, Zomato, OYO, and more. The platform helps users plan interior designs, parties, and even select matching jewelry for special occasions-all within their defined budgets. PocketSmart AI transforms budgeting into an intelligent, user-friendly experience through its smart planners, adaptive forms, and recommendation engine that bridges multiple categories and e-commerce ecosystems.

4. EXACT FEATURES
-----------------
Core Planning Modules:
- Home Interior Planner: Select budget, specify room types (Living Room, Kitchen, Bedroom), quantities for lights, ceiling fans, dining tables, etc. AI recommends cost-effective options across IKEA, Amazon. Recommendations balanced across functionality, style, and price.
- Party Planner: Input total budget, guest count, event type, venue details. AI allocates budget proportionally across catering, decoration, entertainment. Sources from Swiggy, Zomato, OYO. Tailors suggestions based on event type (birthday, corporate, wedding).
- Jewelry Planner: Enter budget, select occasion, define style preferences. Optional outfit image upload for color coordination. AI offers jewelry from Amazon, Flipkart tailored to occasion and style.

Additional Features:
- User Authentication (Register, Login, Logout)
- JWT Token-based authentication
- Session management (/session-info, /session-data)
- Recommendation History tracking
- User Dashboard with recent recommendations and saved queries
- Testimonials page
- Responsive frontend with card-like recommendation displays

6. EXACT API ROUTES
-------------------
POST /generate-home - Generates home interior recommendations
POST /generate-party - Suggests catering, venue, decoration for events
POST /generate-jewelry - Jewelry recommendations with text + image
POST /register - User registration
POST /login - User login, initiates session
POST/GET /logout - Terminates session, redirects to login
POST /token - Issues JWT token after authentication
GET /session-info - Retrieves session metadata (user ID, login status)
GET /session-data - Returns detailed session data for personalization
GET /recommendations-details - Returns detailed AI-generated recommendations
GET /history - Retrieves user's past recommendation queries
/startup - Initializes application services on server start
